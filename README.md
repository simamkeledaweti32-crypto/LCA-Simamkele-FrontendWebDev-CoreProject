# ModernTech HR Portal - LCA Frontend Core Project
By: Simamkele Daweti

## Description
A responsive HR management system for ModernTech Solutions built with Vue 3. 
It handles Employee Management, Payroll, and Leave Requests with data persistence.

## Live Demo
https://chipper-pavlova-2873a8.netlify.app

## Setup Instructions
1. Clone this repository
2. Open index.html in your browser. No installation needed.

## Technologies Used
- Vue 3 for reactive UI
- Bootstrap 5 for styling and responsiveness  
- JavaScript ES6
- localStorage for data persistence

## Key Features Implemented
1. Employee Directory: View, Add employees. Data saves to localStorage.
2. Payroll & Payslips: Auto-calculate tax 18%, deductions, net and annual salary.
3. Leave Management: View all requests, Approve/Deny with live counters.
4. Responsive Design: Works on Desktop and Mobile.
5. Dashboard: Shows total employees, pending leave, payroll stats.
